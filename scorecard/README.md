# Audit scorecard web page

A static page where someone drops in the files they already have (quotes, POs, invoices, receiving lists, Terraform state, cloud inventories, Redfish or Ansible exports, a golden configuration) and gets an Infrastructure Bill of Materials plus a health, drift and supply chain risk scorecard. **Try the sample pod** loads the synthetic pod B02 files and scores them in one click.

Everything runs in the visitor's browser. The page loads [Pyodide](https://pyodide.org) (CPython compiled to WebAssembly) from the jsDelivr CDN, unpacks this repo's `ibom_ingest` and `ibom_risk` packages, and runs `ibom_risk.audit` on the dropped files in memory. Files are never uploaded; the only network requests fetch the runtime and this folder's own files.

It is published at `/scorecard/` of the docs site (the site build copies this folder as-is).

## Files

| Path | What it is |
|---|---|
| `index.html`, `style.css`, `app.js` | The page |
| `py/ibom.zip` | `ibom_ingest` + `ibom_risk` sources, generated by `build.py` |
| `py/wheels/` | Pure-Python wheels the engines need for PDF and XLSX input: pypdf (BSD-3-Clause), openpyxl and et_xmlfile (MIT), unmodified from PyPI |
| `demo/` | Copies of the sample files the demo button loads, plus `demo.json` (file list, as-of and need-by dates), generated by `build.py` |
| `build.py` | Regenerates `py/ibom.zip` and `demo/` |

## Changing the engines

After editing anything in `ibom_ingest/`, `ibom_risk/` or the demo samples, run:

```bash
python3 scorecard/build.py          # regenerate the bundle and demo copies
python3 tests/test_audit.py         # includes a check that they are up to date
```

The same audit runs from the command line:

```bash
python3 -m ibom_risk audit samples/pod-b02/purchasing samples/pod-b02/iac/terraform-state.json \
    samples/pod-b02-ops/live/2026-10-12 --today 2026-10-12 --need-by 2026-10-31
```

## Testing the page locally

Serve the repo root and open `/scorecard/`:

```bash
python3 -m http.server 8000     # then open http://localhost:8000/scorecard/
```

To run without the CDN (offline, or in CI), unpack the `pyodide` npm package (version in `app.js`) somewhere under the served folder and add `?pyodide=/path/to/it/` to the URL.

## How files are recognised

By content, not name: an `.ibom.json` becomes the starting point; CSV, XLSX, PDF and text are purchasing documents; Terraform JSON with `values.root_module` is state, with `resource_changes` a plan, and with `resource_drift` a refresh-only plan (live state); `ansible_facts` JSON and `.ini` inventories go to the Ansible reader; `@odata.type` is Redfish; `Reservations` is `aws ec2 describe-instances` (checked for shadow resources and used as live state); a `rules` list is a golden configuration; a `signals` list is market signals. Anything else is listed as skipped with the reason. Files with no timestamp of their own (Ansible facts, Terraform state) are treated as older than any dated snapshot in the same upload.
