Infrastructure audit scorecard

Drop in the files you already have: quotes, purchase orders, invoices, receiving lists, Terraform state, cloud inventories, Redfish or Ansible exports. You get an Infrastructure Bill of Materials and a scorecard for configuration drift, shadow infrastructure, supply chain risk and lifecycle health.

Your files never leave this browser tab. The open-source I-BOM engines run here, in Python compiled to WebAssembly.

1. Add files

    Which files work?
    PurchasingQuotes, POs, invoices and receiving lists as CSV, XLSX, PDF or text. Column names are matched loosely (Part Number, MPN, Qty, Unit Price, Serial, ...).
    Declared stateterraform show -json state or plan output; Ansible inventory (.ini) with ansible -m setup facts
    Live stateaws ec2 describe-instances, Azure Resource Graph, GCP asset list, EKS cluster and node group JSON, Redfish snapshots, a refresh-only Terraform plan, or gNMI/agent facts
    PolicyA golden configuration file (desired firmware, versions and drift policy) and a market signals file for supply risk
    Existing I-BOMAn .ibom.json file is used as the starting point and enriched by the rest

    File types are recognised from their content, not their names. See the sample files for each format.
